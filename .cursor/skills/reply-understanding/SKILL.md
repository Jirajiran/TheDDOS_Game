# วงจรตอบความเข้าใจ

ทุกข้อความเข้ามา ให้ทำตามลำดับนี้ แล้วแสดงผลในแชท

1. ดูข้อมูลที่ให้ มีอะไรเกิดขึ้น และแนวทางแก้ที่มากับมัน
2. จัดชนิดของข้อมูล เป็นการปรับข้อเดิม หรือการเพิ่มข้อใหม่
3. แต่ละข้อที่ถูกแตะ ให้ทวนข้อมูล แล้วทวนแนวทางแก้พร้อมวิธีที่คาดไว้
4. วิธีที่ตรงคติทั้งห้าและข้อมูลขับเกม ถือว่าถูก
5. วิธีที่ขัดคติ ให้ทักท้วงข้อนั้น แล้วเสนอวิธีที่คาดใหม่
6. แสดงผลทั้งก้อนกลับในแชท ข้อที่ไม่ได้แตะคงไว้

แต่ละข้อใช้สามบรรทัดนี้เท่านั้น บรรทัดเลขคือทวนโจทย์ ไม่เติม `-` บรรทัดแนวทางกับบรรทัดเครื่องหมายเติม `-`

```
1.หัวข้อ : ทวนโจทย์ของข้อนี้
 - แนวทาง คือ วิธีที่คาดไว้
 - ✔ เข้าใจล่ะ
```

ถ้าขัดคติ บรรทัดที่สามเป็นแบบนี้แทน และไม่ใส่บรรทัดเข้าใจล่ะ

```
 -⚠️ผิดคติ คือ เหตุที่ขัด และวิธีที่คาดใหม่
```

แสดง `⚠️` หรือ `✔` อย่างใดอย่างหนึ่งต่อข้อ ถ้าข้อมูลใหม่มาเป็นผิดคติ ให้แก้บรรทัดผิดคติ ไม่ต้องบอกถูก

เมื่อผู้ใช้ยืนยันให้ลงมือ

1. ดูทั้งชุดอีกครั้งว่าทุกข้อถูกแล้ว หรือยังมีการปรับต่อ
2. ถ้ายังมีข้อที่ขัดหรือยังไม่ชัด ให้ทักข้อนั้น และยังไม่ลงมือ
3. ถ้าทุกข้อถูก จึงลงมือ แล้วรอข้อมูลถัดไป
4. ข้อมูลถัดไปอาจเพิ่มบนข้อเดิม หรือปรับข้อเดิมอีกครั้ง ให้กลับไปข้อ 2

คติที่ใช้ตรวจคือห้าข้อในกฎสถาปนิก กราฟแทนกริด ตรวจตามทิศ ท่ออินพุตเดียว ผลจากสถานะ และย้อนด้วยสแนปช็อต รวมถึงข้อมูลขับเกม
