---
ต้นทางเกมหลัก — Art pool / raster (สัญญาเดียวกับ Editor; เกมต้อง boot แบบเดียวกัน)

เป้าหมาย
- ลดการเรียก SVG DOM API ต่อเฟรม: โหลด/สร้างครั้งเดียวตอน loading แล้ว clone จาก pool
- Editor ทำขั้นนี้แล้วใน runLoading → buildArtPool; เกมหลักคู่กันแล้ว

กฎขนาด / สไตล์
- สไตล์ = Lineless Pixel Art (จอความละเอียดต่ำยุคเก่า) ไม่ใช่เวกเตอร์เนียน
- ความละเอียดต้นทางใน pool = 64×64 ต่อช่อง SizeView
- ช่องวางบนแมพ (L3) = 64×64 → แสดง 1:1 จาก pool (nearest-neighbor ถ้าสเกลจอ)
- เฟรมเริ่มจาก SizeView รอบจุดศูนย์กลาง; ถ้ายื่นนอกขอบให้ขยายเฟรม แต่ anchor กลางคงที่
- สี: bucket/quantize + hard alpha (ตัด antialias) เพื่อประหยัดสีและให้เป็นก้อนพิกเซล

Pipeline (loading screen)
1. Parse SVG ต้นทางครั้งเดียวต่อ pack
2. วัด SizeView → center + side; วัด overflow → frame
3. Raster SVG (hi) แล้ว nearest-downsample เป็น 64×N พิกเซล
4. pixelize: hard alpha + palette step → ใส่ pool (progress บนหน้า loading)
5. Runtime: วาดจาก pool (cellSize=64) บนแมพ L3 64
6. Metadata: cellSize (64), frameW/H, anchorX/Y, pixelArt=true

ช่วงเปลี่ยนผ่าน
- [✓] Editor: pack.artPool จาก buildArtPool — composite สำหรับ thumbs + layer keys แยก (body/arm/top/bottom)
- [✓] เกมหลัก: `js/view/artPool.js` + `unitVisual` bake ทีละ layer (lineless); `_armPoses` matrix ยังจาก SVG parse — แอนิเมชันไม่พังเพราะไม่ merge ทั้งตัว
- Match loading มี stage `art_pool`
