# map-path — Path / L1–L3 / BaseChunk / Place snap

สถานะ: ล็อกใน AskKeep §1 + Set A (โค้ด V1 ทำตามแล้วส่วนใหญ่)

อ่านก่อน:
- `Doc/00_hub/AskKeep.txt` §1 ตารางขอบเขต + Place snap
- สเกลจริง = Set A ท้าย AskKeep (Path 1024 · L1 512 · L2 256 · L3 64)

หนึ่งแมปหนึ่งไฟล์ แมปปัจจุบันคือ `data/pack/game_pack.json` ค่ากล้อง มุมภาพ และของดรอปอยู่ `data/pack/presentation.json` กติกาคลื่นอยู่ `data/pack/rules.json`

ทีมเป็นของแมป ใช้ได้ไม่เกิน 6 ทีม แถว (Nature) อยู่นอกจำนวนนี้ และไม่ใช่ที่นั่งผู้เล่น `seatCap` 12 คือเพดานที่นั่งตอนผู้เล่นสู้กันเอง แมปนี้มีทีม 1 ผู้เล่น และทีม 2 ศัตรู แต่ละทีมบอก `hostileTo`

พื้นที่อยู่ `data/pack/areas.json` แต่ละพื้นที่เป็นสี่เหลี่ยมและอาจมีคำสั่ง เช่น (EnterArea) แล้ว (MoveTo) ไป id พื้นที่ใน `target` คำสั่ง (EnterArea) เก็บ (area.teams) และให้ (area.team) เท่ากับทีมแรก ซิมยังเทียบทีมแรก ทีมถัดไปยังไม่มีผล ยูนิตรับคำสั่งเมื่อทีมตรงกับพื้นที่ ผู้เล่นไม่ถูกสั่ง สี่ขอบเป็นทีม 2 `player_start` กับ `enemy_middle` ไม่มีคำสั่งนี้จึงไม่มีทีม

ตารางเกิดของเกมที่เล่นอยู่ยังอยู่ `data/pack/spawns.json` แถวบอทมีคลื่น เวลาเริ่ม ทีม id พื้นที่ และรายการ `ชนิดยูนิต:จำนวน` ของที่ถือมาจากชุดเริ่มของร่างนั้น ไฟล์แมปของเอดิเตอร์มีแถว (Host) กับแถว (Player) คนละชนิดกับเวฟ แต่ละแถวมี (Area) ถ้ายังไม่มีพื้นที่ จุดเกิดเป็นกลางตาราง (Path) ไม่ได้อยู่ที่ชื่อพื้นที่ `player_start` รายละเอียดแถวเกิดอยู่ที่ `Doc/03_domains/editor/README.md` ข้อ 4.2.3
