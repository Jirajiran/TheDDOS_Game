## แผงอัปเกรด (ล็อก)

แผงอยู่ใน `Asset/AssetSVG/Ui/PlayerUIGamePlay.svg` ภายใต้ `Anchor_Top_Left_3` ชิ้นที่ใช้คือ `Panel_Upgrate`, `Slot_CurrentWeapon`, `LoadUpgrate`, `Btn_Press_false_TakeWeapon`, `Slot_Done_Upgrate` เปิดเมื่อซิมส่ง `pendingUi` ชนิด `upgrade` จากโรงงาน `FACTORY_WEAPON` แล้ว `consumePendingUi` เรียก `setUpgradeOpen` เดินออกจากโรงงานแล้วซ่อนแผง

รับเฉพาะช่องที่ `kind` เป็นอาวุธ และมีแถวใน `data/pack/weapon_upgrades.json` กด `Btn_Press_false_TakeWeapon` แล้วซิมเลือกเอง ถ้ามีผลพร้อมจึงรับคืน ไม่งั้นฝากปืนในช่องปัจจุบัน คลิกหรือลากลง `Slot_CurrentWeapon` ฝากอย่างเดียว คลิกหรือลากลง `Slot_Done_Upgrate` รับคืนอย่างเดียว ปืนผลมีแถวใน `items.json` จึงเข้าช่องว่างได้ และบอกว่าเต็มเฉพาะเมื่อไม่มีช่องว่าง ชื่อโรงงานย่อให้พอกรอบ ปุ่ม Take พักที่ False และตอนกดเป็น True จาก `Btn.svg` ทีละใบ ตัวหนังสือบน HUD เลือกไม่ได้ ยกเว้นช่องแชท `GunDetail` บอกว่าใส่ได้หรือไม่ได้ค้าง `gunDetailDwellSec` วินาที

`btn_interactive` โชว์เมื่อเป้าหมายใกล้สุดเป็นเจน ฐาน หรือโรงงาน ไม่โชว์เพราะถืออาวุธ กดแล้วเข้าท่อ `INTERACT` ตาม `Doc/03_domains/input/`

## ชั้นโลกและแถบเลือดบล็อก

วาดแยกสามรอบ ตัวบล็อก แล้วปืนป้อม แล้วแถบเลือดหลังยูนิตกับกระสุน แถบเป็นภาพอย่างเดียว ไม่เข้าซิม

แถบโชว์เมื่อเลือดไม่เต็ม และจุดกลางบล็อกอยู่ภายใน `blockHpBarRadiusL3` ช่องจากผู้เล่นคนนี้ ถ้าเกิน `blockHpBarCap` เหลือก้อนที่ใกล้สุด ตัวเลขอยู่ใน `data/pack/game_pack.json`

## ระบบเล็กบน HUD

เฟรมดีบักซ่อนตอนเริ่ม กด F3 จึงโชว์ แผงโรงงานเปิดเมื่อซิมส่ง `upgrade` เพราะ `setUpgradeOpen` ผูกกับ HUD แล้ว กด E ขณะแผงโรงงาน เจน หรือฐานเปิดอยู่จะปิดแผง ไม่ส่งแอ็กชันซ้ำ

ผลคราฟต์อยู่ที่ `notification_AlignCenter` สีแดงในแผงคราฟต์ จนกว่าจะเลือกสูตรอื่น เปลี่ยนหมวด ปิดแผง หรือคราฟต์ครั้งถัดไป `Detail_Item` ยังเป็น lore

สลับช่องแค่เลือกของ เกราะกับโล่สวมเมื่อคลิกช่องนั้น จำที่ `wornArmorSlot` กับ `wornShieldSlot` คนละช่องคือคนละชิ้น กดช่องที่สวมอยู่ซ้ำแล้วถอด ของยังอยู่ในช่อง สีเหลืองโปร่งทับเฉพาะช่องนั้น เสื้อเกราะวาดแผ่นสีจาก `color` ของไอเทมที่กลางตัวเมื่อ `activeArmorId` ถูกตั้ง

กระเป๋าสวมเมื่อคราฟต์ได้หรือเมื่อเลือกช่อง ระดับต่ำกว่าใบที่ใส่อยู่ถูกปฏิเสธและค้างในช่อง กล่องช่องของระดับที่สวมใช้ภาพ `Ui_Ui_1_5` ชุดเดียวกับหกช่องหลัก และโชว์รวมช่องว่าง

`GunDetail` โชว์ของช่องที่เลือก ชี้ชิ้นที่มีชื่อค้าง `gunDetailDwellSec` วินาทีแล้วสลับเป็นชื่อกับ lore สั้นจากตัวเลขในแพ็ก ปล่อยไปที่โล่งแล้วกลับของช่องปัจจุบัน `Skill_Show_2` โชว์ฮีลแต่กดไม่ได้ ซิมฮีลเองตาม `cooldownSec` กับ `amount` ใน `skills.json`
