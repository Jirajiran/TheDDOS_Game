เป้าหมาย: ใช้ editor สร้างแมพ แล้วให้เกมเลือกเล่นได้หลายแมพ (data-driven)  
หมายเหตุปัจจุบัน: เกมยังไม่อ่านไฟล์แมพจาก editor แทน `data/pack/`

---

## คิวหลัก (เรียงลำดับ)

### 1. แก้ระบบ UX ใน editor
- [ ] ปรับการใช้งานหน้า `editor.html` ให้วางของ/นำทางชัดขึ้น
- [ ] คงแยกหน้า editor กับ `index.html` ตามสเปกโดเมน

### 2. ระบบ Draw วางตำแหน่ง unit / block
- [ ] วาด/วางตำแหน่ง unit และ block บนแมพ
- [ ] ยึดพิกัด/ชั้นตาม `map-path` (Set A) · ไม่ยัดทุกอย่างลง grid โดยไม่จำเป็น

### 3. ระบบทดสอบเล่นใน Editor
- [ ] เล่นลองแมพจากใน editor ได้โดยไม่ต้องพึ่งเมนูเกมเต็มรูปแบบ
- [ ] ใช้กฎ/Engine ชุดเดียวกับเกมเมื่อเป็นไปได้ (ไม่โกงกฎ)

### 4. ระบบ Export แมพ JSON → ใส่ list
- [ ] ส่งออกแมพเป็น JSON ตามสัญญาไฟล์
- [ ] ลงทะเบียนใน list ให้เมนู/โหมดเลือกเล่นได้หลายแมพ
- [ ] เกมอ่านรายการจากข้อมูล ไม่ hardcode แมพทีละใบใน if กระจาย

### 5. Multiplayer แบบ alone + ตั้งค่าจาก editor (รอรับ)
- [ ] โหมด alone ใช้ค่าที่ตั้งใน editor (สปอน · ทีม · พารามิเตอร์แมพ)
- [ ] ค่าถูก export มากับแมพ/list แล้วเกมรอรับเป็นข้อมูล

### 6. Multiplayer database — **ภายหลัง / ต้องมี server**
- [ ] ห้องโลก · คลัง · sync ผ่านฐานข้อมูล
- [ ] **ไม่ผสมเฟส portfolio static** (itch / Netlify / GitHub Pages)  
- [ ] เปิดหลังคิว 1–5 ทำให้เล่นหลายแมพแบบ static ได้จริง
