1. Shield System (ระบบโล่)
พฤติกรรมเมื่อพัง: หากโล่แตก/พัง ให้ลบหรือนำออกจาก Slot ทันที

ข้อยกเว้น: โล่ประเภท Shield Energy ไม่ต้องหายไปจาก Slot เมื่อพัง (ให้รอฟื้นฟูหรือจัดการสถานะตามกลไกของ Energy Shield แทน)

2. Vehicle & Turret System (ระบบยานพาหนะ ป้อมปืน และ AI ผู้ขับ)
โครงสร้างการสืบทอด (Inheritance):

Vehicle สืบทอดมาจาก Unit และปรับแต่งระบบการเคลื่อนที่ (Movement) ใหม่

Turret บนรถ สืบทอดมาจาก Turret และสืบทอดต่อจาก Unit สำหรับการหมุนและการถือ Weapon

ปัญหาที่พบ:

Movement ทะลุขอบฉาก: ยานพาหนะยังเคลื่อนที่ทะลุออกนอกฉากไปได้ เหมือนไม่ได้รับการสืบทอดหรือ override ส่วนของ Collider / ขอบเขตการเคลื่อนที่จาก Unit อย่างถูกต้อง

Turret หันแบบกระตุก/ทันที (Snap rotation): ป้อมปืนควรค่อย ๆ หมุนหันตามเป้าหมาย แต่ปัจจุบันกลับหันตัดช่วงหรือหันทันที เหมือนไม่ได้ใช้ระบบการหมุนที่สืบทอดมา

AI / Bot ขับรถไม่ได้: Bot ผู้ขับไม่รู้วิธีสั่งการหรือคำนวณการเคลื่อนที่ตามรูปแบบ Movement ใหม่ของ Vehicle (หรือขาด interface/API ที่รองรับการเคลื่อนที่แบบใหม่)


3. Bullet / Projectile Assets (ระบบกระสุนและ Asset)
ประเด็นที่ต้องตรวจสอบ: ยืนยันว่าเกมกำลังเรียกใช้ Asset กระสุนตัวจริง (ตัวใหม่ที่วาดมาแล้ว) หรือยังดึง ของเก่า มาใช้อยู่

ข้อสงสัย: มีการปะปนหรือรวมกันของ Asset เก่าและใหม่ในโปรเจกต์/Prefab/ระบบกระสุนหรือไม่ ทำให้ไม่แน่ใจว่าตัวไหนถูกใช้งานจริง


แนวคิดการออกแบบ
1. การสร้างเส้นกราฟจำลองจาก "ความเร็วต้น" (Velocity-Aware Curve Generation)แนวคิดที่ให้บอทไม่ต้องรับรู้ความเร็วต้นตลอดเวลา แต่ใช้ความเร็วต้นเป็นตัวแปรตั้งต้นในการสร้างเส้นกราฟ (Spline) สามารถทำได้ผ่าน Hermite Spline หรือ Cubic Bezier Curve:สมการเวกเตอร์เริ่มต้น ($P_0$ และ $T_0$): เมื่อเริ่มคำนวณเส้นทาง ให้ดึงตำแหน่งปัจจุบันเป็นจุดเริ่มต้น ($P_0$) และนำ เวกเตอร์ความเร็วปัจจุบัน ($\vec{v}_0$) มาคูณกับค่าคงที่ของแรงเฉื่อย (Momentum Factor) เพื่อสร้างเป็น จุดควบคุมแรก (Control Point / Tangent $T_0$)ผลลัพธ์ที่ได้: หากรถกำลังวิ่งมาด้วยความเร็วสูง เส้นกราฟที่ถูกสร้างขึ้นจะมีรัศมีโค้งที่กว้างและทอดยาวไปข้างหน้าตามทิศทางเดิมก่อนจะค่อยๆ โค้งเข้าหาเป้าหมาย ทำให้รถไม่หักเลี้ยวกะทันหัน (ไม่หักดิบ) โดยที่ตัวบอทในเฟรมถัดๆ ไปแค่ "ไถลตามจุดบนเส้นกราฟ" ไปเรื่อยๆการเก็บค่าความโค้งล่วงหน้า (Curvature Profiling): ระหว่างที่สร้างจุดตัวอย่าง splinePoints[] ให้คำนวณค่าความโค้ง (curvature[]) เก็บไว้ด้วย เพื่อให้ระบบขับเคลื่อนรู้ล่วงหน้าว่าต้องผ่อนคันเร่งก่อนถึงโค้งหักศอก2. การเคลื่อนที่ตามเส้น (Pure Pursuit / Spline Following)เมื่อมีเส้นกราฟใน Blackboard แล้ว บอท (หรือส่วนตัวถัง Hull) ไม่ต้องคิดหาทางใหม่ทุกเฟรม:Lookahead Point: บอทจะเลื่อนตัวชี้ (splineCursor) ไปข้างหน้าตามระยะมองล่วงหน้า (Lookahead Distance) บนเส้นกราฟ แล้วส่งเวกเตอร์ทิศทางไปยังตัวควบคุมการเคลื่อนที่การควบคุมพวงมาลัย (Steering): ในชั้นฟิสิกส์ จะแปลงเวกเตอร์เป้าหมายเป็นแรงขับเคลื่อนและมุมเลี้ยวแบบ Bicycle / Ackermann Steering (รัศมีวงเลี้ยวแปรผันตามความเร็ว) แต่หากรถหยุดนิ่ง (currentSpeed <= minTurnSpeed) สามารถปลดล็อกโหมด Pivot Turn เพื่อหมุนตัวถังอยู่กับที่ให้ตรงกับทิศทางเริ่มต้นของเส้นกราฟก่อนออกตัวได้3. การเก็บตัวแปรสิ่งกีดขวางและการหลบหลีก (Obstacle Avoidance)เพื่อไม่ให้ต้องคำนวณเส้นกราฟใหม่ทั้งหมดทุกครั้งที่เจอสิ่งกีดขวางเล็กน้อย ให้แบ่งการหลบออกเป็น 2 ระดับ:ระดับที่ 1: การเบี่ยงหลบชั่วคราว (Local Steering / Raycast Offset)เก็บข้อมูลสิ่งกีดขวางรอบตัวในระยะสายตา (เช่น ผ่าน senseIndex หรือ Raycast รูปพัดด้านหน้า)หากมีสิ่งกีดขวางขวางอยู่บนเส้นกราฟ ให้บวก เวกเตอร์แรงผลักด้านข้าง (Lateral Offset) เข้าไปกับจุด Lookahead Point ชั่วคราว ทำให้รถเบี่ยงออกด้านข้างเพื่อหลบสิ่งกีดขวาง แล้วค่อยๆ ดึงตัวเองกลับเข้าสู่เส้นกราฟหลักเมื่อพ้นระยะ โดยไม่ต้องสร้างกราฟใหม่ระดับที่ 2: การอ้อมสิ่งกีดขวางขนาดใหญ่ (Virtual Waypoint / Tangent Orbit)หากสิ่งกีดขวางปิดตายเส้นทางด้านหน้าทั้งหมด (เช่น กลุ่มยูนิตยืนขวางเต็มช่องทาง) ระบบจะคำนวณจุดศูนย์กลางและรัศมีของกลุ่มสิ่งกีดขวาง แล้วสร้าง จุดแวะชั่วคราว (virtualWaypoint) ที่มุมสัมผัสด้านข้าง ($\pm 90^\circ$ ถึง $\pm 135^\circ$) เพื่อให้รถตีวงอ้อมโอบสิ่งกีดขวางนั้น ก่อนจะกลับเข้าเส้นทางหลัก4. เงื่อนไขการคำนวณเส้นทางใหม่เมื่อเกิดการชน (Collision & Re-pathing)หากเกิดการชน หรือรถเบี่ยงหลบจนหลุดออกจากเส้นกราฟเดิมไปไกล ระบบควรมีกลไก Reset และคำนวณกราฟใหม่ (Re-compute Spline) ใน 3 กรณีนี้:เกิดการปะทะ (OnCollision / Impact Event): เมื่อชนเข้ากับสิ่งกีดขวาง ความเร็วต้น ($\vec{v}_0$) จะเปลี่ยนไปอย่างกะทันหัน (เช่น ความเร็วลดลงเหลือ 0 หรือเด้งถอยหลัง) ให้ล้างเส้นกราฟเก่าทิ้งทันที แล้วใช้ ความเร็วหลังการชน ($\vec{v}_{\text{new}}$) เป็นค่าตั้งต้นในการสร้างเส้นกราฟชุดใหม่หลุดออกนอกระยะเส้นทาง (Off-Track Threshold): หากรถถูกแรงระเบิดหรือถูกเบียดจนระยะห่างจากจุดปัจจุบันไปยังจุดที่ใกล้ที่สุดบน splinePoints[] เกินค่าที่กำหนด (maxDeviationDistance) ให้สั่งคำนวณเส้นกราฟใหม่จากตำแหน่งและความเร็วปัจจุบันรถติดหล่ม / ขยับไม่ได้ (Stuck Escalation): หากบอทพยายามเร่งเครื่องแล้วแต่ระยะทางขยับน้อยกว่าเกณฑ์นานเกินเวลาที่กำหนด (เช่น 1.2 วินาที) ให้ส่งสัญญาณ PATH_BLOCKED เพื่อให้ระบบวางแผนระดับบน (Path Planner / General) เปลี่ยนจุดหมายย่อย (Pivot) หรือสั่งถอยหลังตั้งหลักก่อนสร้างเส้นกราฟใหม่ข้อควรระวังเพิ่มเติมสำหรับการออกแบบ 2D:ระยะ Lookahead แบบแปรผัน (Dynamic Lookahead): ควรปรับระยะมองล่วงหน้าบนเส้นกราฟให้แปรผันตามความเร็ว (Lookahead = baseDist + currentSpeed * k) ถ้ารถวิ่งเร็วแล้วยังใช้ระยะมองใกล้เกินไป รถจะส่ายไปมา (Oscillation) บนเส้นกราฟ แต่ถ้ามองไกลขึ้นตอนวิ่งเร็ว รถจะเข้าโค้งได้นุ่มนวลขึ้นมากครับ

การใช้ระบบ Hybrid (เลี้ยวตีวงแบบรถยนต์ตอนวิ่ง + หมุนตัวถังอยู่กับที่แบบรถถังตอนหยุดนิ่ง) เป็นวิธีที่ลงตัวที่สุดสำหรับเกม 2D เพราะทำให้รถดูมีน้ำหนักสมจริงตอนวิ่ง แต่ไม่ติดบั๊กเลี้ยวไม่พ้นตามซอกแคบๆเมื่อนำกลไกนี้มาผสานเข้ากับท่อ Stage (APPROACH_PATH) $\rightarrow$ MOVE(dx, dy) $\rightarrow$ applyActions (Unified Input) จะสามารถวางโครงสร้างสมการและลอจิกได้ 3 ส่วนดังนี้ครับ:1. การสร้างเส้นกราฟจำลอง (Spline) ตามสไตล์รถยนต์และรถถังเมื่อเริ่มออกตัวหรือคำนวณเส้นทางใหม่ (Re-path) ให้สร้างเส้นโค้ง Cubic Bezier โดยดูสถานะความเร็วต้น ($\vec{v}_0$) เป็นตัวกำหนดจุดควบคุมแรก ($P_1$):กรณีที่ 1: รถกำลังเคลื่อนที่อยู่ (currentSpeed > minTurnSpeed) — สไตล์รถยนต์
นำเวกเตอร์ความเร็วปัจจุบันมาคำนวณเป็นจุดควบคุมแรก เพื่อให้เส้นโค้งทอดยาวไปตามแรงเฉื่อยเดิมก่อนเลี้ยว:$$P_1 = P_0 + (\vec{v}_0 \times \text{momentumFactor})$$(ทำให้รถไม่หักดิบ แต่ค่อยๆ ตีวงโค้งเข้าหาจุดหมาย)กรณีที่ 2: รถหยุดนิ่ง (currentSpeed <= minTurnSpeed) — สไตล์รถถัง
ไม่จำเป็นต้องดัดโค้งรับแรงเฉื่อยเริ่มต้น ให้วางจุดควบคุมแรก ($P_1$) ชี้ตรงไปยังจุดหมายถัดไป ($P_2$) ได้เลย เพราะเดี๋ยวตัวถังจะใช้วิธีหมุนอยู่กับที่ (Pivot Turn) ให้ตรงกับมุมเริ่มต้นของเส้นกราฟก่อนเร่งเครื่องออกตัว2. การแปลงคำสั่ง MOVE(dx, dy) ในชั้น applyActions (Hybrid Physics)ในฝั่งบอท (Stage APPROACH_PATH) ยังคงทำหน้าที่แค่เลื่อนตัวชี้ splineCursor และหลบสิ่งกีดขวางเพื่อส่งเวกเตอร์ MOVE(dx, dy) ออกมาตามปกติ ส่วนการตัดสินใจว่าจะ "หมุนอยู่กับที่" หรือ "วิ่งตีวงโค้ง" จะอยู่ในฟังก์ชัน applyActions ของ Vehicle:JavaScriptfunction applyVehicleMovement(vehicle, targetDx, targetDy, curvature, dt) {
  const targetAngle = Math.atan2(targetDy, targetDx);
  const angleDiff = normalizeAngle(targetAngle - vehicle.heading); // ส่วนต่างมุม (-PI ถึง PI)
  const isStopped = vehicle.currentSpeed <= vehicle.minTurnSpeed;

  // โหมด 1: รถถัง (Pivot Turn) — ทำงานเมื่อรถหยุดนิ่งและมุมหันยังไม่ตรงกับเส้นกราฟ
  if (isStopped && Math.abs(angleDiff) > vehicle.pivotThresholdRad) {
    const turnDir = Math.sign(angleDiff);
    const turnStep = vehicle.pivotTurnSpeed * dt;
    
    // หมุนตัวถังอยู่กับที่จนกว่าจะตรงทิศทางเส้นกราฟ
    vehicle.heading += Math.abs(angleDiff) < turnStep ? angleDiff : turnDir * turnStep;
    vehicle.currentSpeed = 0; // ล็อกความเร็วไว้จนกว่าจะหันเสร็จ
    return;
  }

  // โหมด 2: รถยนต์ (Ackermann / Bicycle Steering) — ทำงานเมื่อออกตัววิ่งแล้ว
  // 1. คำนวณความเร็วเป้าหมาย (ชะลอความเร็วอัตโนมัติถ้าข้างหน้าเป็นโค้งหักศอก)
  const maxAllowedSpeed = vehicle.maxSpeed * (1 - curvature * vehicle.cornerBrakeFactor);
  vehicle.currentSpeed = moveTowards(vehicle.currentSpeed, maxAllowedSpeed, vehicle.accel * dt);

  // 2. จำกัดองศาการเลี้ยว (Steer Angle) ไม่ให้หักเกินลิมิตของล้อรถยนต์
  const steerAngle = clamp(angleDiff, -vehicle.maxSteerAngle, vehicle.maxSteerAngle);
  
  // 3. อัตราการหมุนตัวถังแปรผันตามความเร็วและฐานล้อ (ยิ่งวิ่งช้า วงเลี้ยวยิ่งแคบ)
  const angularVelocity = (vehicle.currentSpeed / vehicle.wheelBase) * Math.sin(steerAngle);
  vehicle.heading += angularVelocity * dt;

  // 4. อัปเดตเวกเตอร์ความเร็วตามทิศหัวรถ (ลดการไถลด้านข้างด้วย Grip)
  vehicle.vx = Math.cos(vehicle.heading) * vehicle.currentSpeed;
  vehicle.vy = Math.sin(vehicle.heading) * vehicle.currentSpeed;
}
3. ลำดับการแก้ปัญหาเมื่อเกิดการชน (Collision Recovery)เมื่อรถวิ่งชนสิ่งกีดขวางจนความเร็วตกลงมาเป็น 0 ระบบ Hybrid นี้จะช่วยให้การกู้คืนเส้นทางทำได้ง่ายขึ้นมาก:จังหวะปะทะ (OnCollision): ความเร็ว currentSpeed ถูกตัดเป็น 0 ทันที และล้างเส้นกราฟเก่าทิ้งจังหวะถอยหลังตั้งหลัก (Reverse Step): หากระยะห่างด้านหน้ารถชิดสิ่งกีดขวางเกินระยะปลอดภัย (frontClearance < minSafeDist) ให้บอทส่งคำสั่งถอยหลังตรงๆ เป็นเวลาสั้นๆ (เช่น 0.4 วินาที) เพื่อให้มีพื้นที่ว่างด้านหน้ารถจังหวะหมุนตัวถัง + สร้างกราฟใหม่: เมื่อถอยจนได้ระยะและหยุดนิ่ง (currentSpeed === 0) ระบบจะสร้างเส้นกราฟชุดใหม่ไปทางช่องว่างที่หลบสิ่งกีดขวาง แล้วเข้า โหมดรถถัง (Pivot Turn) หมุนตัวถังอยู่กับที่ให้หันหน้าเข้าหาเส้นกราฟใหม่จนตรง ก่อนจะเร่งเครื่องวิ่งต่อใน โหมดรถยนต์ ทันทีข้อดีของการผสาน 2 ระบบนี้เข้ากับสถาปัตยกรรมเดิม:ป้อมปืน (Turret) เล็งแม่นยำขึ้น: เพราะ Turret ผูกติดกับพิกัดของ Hull การที่ตัวถังค่อยๆ โค้งหรือหมุนด้วยความเร็วเชิงมุมที่แน่นอน ทำให้ระบบคำนวณดักทางกระสุน (Lead Target) ของป้อมปืนไม่ต้องรับมือกับแรงกระชากกะทันหันรองรับ BUFF_MOBILITY_KILL ได้ทันที: หากรถโดนยิงจนติดสถานะ Mobility Kill แค่ตั้งค่า maxSpeed = 0 และ pivotTurnSpeed = 0 รถจะหยุดนิ่งและล็อกตัวถังทันที โดยที่ Turret ด้านบนยังหมุนยิงต่อได้ตามปกติ
